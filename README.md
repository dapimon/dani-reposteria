# Catálogo web

Starter de una web tipo catálogo para Dani Repostería y Panadería, inspirada en la estructura recomendada a partir de La Liebre:
- Hero visual
- Categorías
- Catálogo de productos
- Sobre nosotros
- Galería
- CTA
- WhatsApp
- Footer

## Requisitos
- Node.js 20 LTS recomendado
- npm

## Ejecutar

```bash
npm install
npm run dev
```

Abre http://localhost:3000

## Personalización rápida

1. Cambia `MI MARCA` en `app/page.tsx`.
2. Cambia productos/precios en `data/products.ts`.
3. Cambia `WHATSAPP_NUMBER` por tu número con código de país, sin `+` ni espacios.
4. Coloca `hero.jpg` en `public/images/`.
5. Sustituye los placeholders de producto/galería por imágenes reales.
6. Ajusta colores en `app/globals.css`.

## Siguiente iteración

Cuando se tenga el export/capturas del diseño de Canva, ajustar:
- paleta exacta
- tipografías
- tamaños
- composición
- logo
- fotografías
- textos
- tarjetas de producto

La primera versión no incluye carrito ni pagos: el CTA de producto lleva a WhatsApp.
